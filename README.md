# Mission Control Web UI (v1)

Start lokal im Mission-Control-Ordner:

```bash
cd /home/marco/.openclaw/workspace/apps/mission-control/web
python3 -m http.server 8090
```

Dann im Browser öffnen:
- http://localhost:8090

Features v1:
- KPI-Cards (6 KPI-Sets)
- Task-Tower Tabelle
- Status-Filter
- Top-Risiken / Eskalationsliste
