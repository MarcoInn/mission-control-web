Run content like an operating system.

## Weekly cadence
- Monday: angle decisions + production brief
- Tuesday-Wednesday: creation (LP, ads, captions, email)
- Thursday: launch tests
- Friday: winner review (scale/hold/cut)
- Sunday: next-week board

## Required assets per week
- 1 LP pass
- 6 short-form creatives
- 10 captions/hooks
- 3 email blocks (welcome/reminder/offer)

## Standard decision template
- Recommendation
- 3 facts
- Options + risk
- Uncertainty/validation
- Next step

## KPI dashboard minimum
- CTR
- LP-CVR
- ATC rate
- CAC
- First-pass success rate

## Governance
- One source-of-truth message map
- Versioned assets
- Compliance check before publish
- No external publishing without explicit approval
