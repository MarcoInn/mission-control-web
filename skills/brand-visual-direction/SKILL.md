---

Design visuals with strategic purpose, not decoration.

## Visual category system (must map to conversion flow)
1) Hero human-in-context (product in use)
2) Product clarity (starter/plus packshots)
3) Decision support (comparison visuals)
4) Trust/transparency visuals (quality commitments)
5) Routine execution visuals (timeline/how-it-works)
6) CTA momentum visual (decision moment)

## Quality rules
- Premium-natural tone, calm contrast, clean composition
- One focal point per visual
- Strong mobile crop readability
- No generic icon clutter
- No internal/dev language inside customer visuals

## Production checklist
- Define objective per visual (attention, trust, decision, action)
- Create asset variants for desktop/mobile
- Add descriptive alt text
- Optimize weight and dimensions
- Verify consistency across the page

## Output protocol
- Visual map (section → asset → purpose)
- 3 strongest visual upgrades
- First 3 QA checks (mobile, readability, conversion path)
