Build UGC as a repeatable performance engine.

## Core workflow
1) Choose one funnel goal (TOF/MOF/BOF)
2) Select one angle (routine, clarity, trust, objection)
3) Create script package:
- Hook (0-3s)
- Problem (3-8s)
- Solution demo (8-20s)
- CTA (final 3-5s)
4) Add shotlist + creator instructions
5) Define test KPI and next iteration trigger

## Shot principles
- Human face early (first 2 seconds)
- Product interaction visible
- Real-life context (kitchen, desk, gym bag)
- Subtitles readable on mobile

## Compliance guardrails
- No cure/medical/disease claims
- No guaranteed outcomes
- Keep claims routine/wellbeing-focused

## Iteration loop
- Keep top winner angle
- Iterate 2 challengers weekly
- Archive loser with reason

## Output format
- 3 scripts (15s, 25s, 35s)
- 1 shotlist per script
- KPI targets (CTR, hold rate, LP-CVR)
- Next test action
