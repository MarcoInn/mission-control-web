# Free/Open Model Selection Matrix (Brand Content)

## Image models
- SDXL: reliable baseline for product/lifestyle key visuals
- Preferred use: hero stills, product scenes, storyboards

## Video models (open/free ecosystem)
- Stable Video Diffusion (img2vid): good for animating approved stills into short loops
- CogVideoX: stronger text-to-video narratives, heavier compute
- LTX-Video: fast generation workflows, useful for iteration speed

## Practical recommendation for this workspace
1. Create high-quality still first (brand-approved)
2. Animate to short video via img2vid model
3. Polish in ffmpeg (cuts, captions, pacing, CTA end card)

## Quality scoring template (1-5)
- Hook power (first 2 sec)
- Product readability
- Human authenticity
- Brand fit (premium-natural)
- CTA clarity

Ship only assets with total >= 20/25.
