# AURANEM — UGC Production Board V1

## Objective
Build a repeatable weekly UGC engine with one winning control + two challenger variants per week.

## Weekly Cadence
- **Monday:** KPI review (last 7 days), select 1 control angle + 2 challenger angles
- **Tuesday:** Script lock (3 x 15s), subtitle/text-safe checks, shotlist finalization
- **Wednesday:** Shoot day (creator + backup creator), capture hooks + B-roll library
- **Thursday:** Edit + versioning (V1/V2/V3), QA for mobile-safe text zones
- **Friday:** Launch tests (ad sets + organic), tracking sheet update
- **Saturday:** Mid-cycle check (hook hold rate, 3s view rate, CTR)
- **Sunday:** Learning memo + next week angle decisions

## KPI Targets (Performance Baseline)
- **Hook hold rate (0–2s):** > 72%
- **3-second view rate:** > 35%
- **CTR (UGC ad):** > 1.8%
- **Landing page CVR from UGC traffic:** > 2.5%
- **Thumb-stop score (qualitative):** face visible in first 2s + clear promise in subtitle

## Iteration Rules
1. Keep one control video running weekly unless it drops below KPI thresholds for 5 consecutive days.
2. Launch two challengers every week:
   - Challenger A: new hook
   - Challenger B: same hook, different persona/scene
3. Archive losing variants with reason code:
   - H1 = weak first 2s
   - T1 = subtitle/readability issue
   - C1 = CTA unclear
   - A1 = angle mismatch
