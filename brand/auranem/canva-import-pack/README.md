# AURANEM Canva Import Pack (No live browser editing required)

This package lets you import a prebuilt PowerPoint into Canva (web or mobile), then edit text and export final creatives.

## Deliverables
- `auranem_canva_import_template_5pages.pptx` (5 pages)
- `auranem_source_assets_and_copy.zip` (source PNGs + copy placeholders)
- `source-assets/` (unzipped source folder)

## Page Map (inside PPTX)
1. Hero 1080x1350
2. Hero 1920x1080
3. Ad Static 1080x1350
4. Story 1080x1920
5. Reel Cover 1080x1920

Each page includes:
- existing AURANEM brand visual (60-caps / white-lid from latest assets)
- editable text placeholders (headline/subheadline/CTA)
- dashed safe-zone guide

---

## How to import into Canva (Desktop/Web)
1. Open Canva in browser and sign in.
2. From home screen, click **Create a design** (top right).
3. Click **Import file**.
4. Select `auranem_canva_import_template_5pages.pptx`.
5. Wait for Canva to convert all 5 pages.
6. Open the imported design.
7. Click any text box to edit headline/subheadline/CTA.
8. Optional: Upload additional PNGs from `auranem_source_assets_and_copy.zip` if you want to swap visuals.
9. Export each page as needed: **Share → Download** (PNG/JPG/PDF/MP4).

## How to import into Canva (Mobile App)
1. Open Canva app (iOS/Android) and sign in.
2. Tap **+** (Create).
3. Tap **Import file** / **Upload files**.
4. Choose `auranem_canva_import_template_5pages.pptx` from Files.
5. Let Canva finish conversion.
6. Open the imported multi-page design.
7. Tap text elements to edit placeholders.
8. If needed, upload images from `auranem_source_assets_and_copy.zip` (extract zip first on phone).
9. Tap **Share → Download** and export required pages/formats.

## Notes
- PowerPoint imports into Canva as editable elements, but final per-channel crop may vary by placement.
- Keep critical text/logo inside safe-zone overlays.
- For Stories/Reels, preserve top and bottom UI-safe margins.
